# Event & Ticket Booking Platform

Full-stack event management and ticket booking system.

## Stack
- Mobile: TypeScript + React Native
- API: NestJS REST API
- Dashboards: Organizer Dashboard & Admin Dashboard
- Infra: Docker Compose + Dockerfiles

## Applications
- Mobile App
- Organizer Dashboard
- Admin Dashboard

## Features
- Event Creation
- QR Tickets
- Refunds
- Discount Codes
- Sponsors
- Notifications
- Calendar
- Analytics
- Reports
- Messaging
- Reviews
